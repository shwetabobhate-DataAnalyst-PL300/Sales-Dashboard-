Project Description
Sales Performance Dashboard | Power BI
Overview
This project showcases an end-to-end Sales Performance Dashboard built in Microsoft Power BI to help businesses monitor key sales metrics, analyze profitability, and identify growth opportunities through interactive visualizations.
The dashboard enables decision-makers to explore sales trends across multiple dimensions including year, month, payment mode, sales type, product, and category.
________________________________________
Key Business Objectives
•	Monitor overall business performance
•	Track sales, purchases, and profit
•	Analyze profit margins and profitability trends
•	Compare different sales channels
•	Identify top-performing products and categories
•	Understand customer payment preferences
•	Enable interactive filtering for better decision-making
